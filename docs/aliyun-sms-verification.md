# 阿里云短信验证配置

New API 可以在保留邮箱验证的同时启用阿里云短信验证。两个开关同时开启时，新用户可以自行选择邮箱或短信完成注册验证。

生产开通、运营商报备、上线验收、巡检、故障处理和密钥轮换请执行 [EBM中转站阿里云短信服务 SOP](./aliyun-sms-sop.md)。

## 前置条件

1. 在阿里云短信服务完成资质、短信签名和验证码模板审核。
2. 模板中必须包含变量 `code`，例如：`您的验证码为 ${code}，10 分钟内有效。`
3. 创建一个仅授予短信发送权限的 RAM 用户并生成 AccessKey。不要使用阿里云主账号 AccessKey。

## Coolify 环境变量

在 New API 服务的环境变量中添加：

```dotenv
ALIBABA_CLOUD_ACCESS_KEY_ID=你的AccessKey ID
ALIBABA_CLOUD_ACCESS_KEY_SECRET=你的AccessKey Secret
ALIYUN_SMS_REGION_ID=cn-hangzhou
ALIYUN_SMS_SIGN_NAME=已审核通过的短信签名名称
ALIYUN_SMS_TEMPLATE_CODE=SMS_123456789
```

保存环境变量并重新部署。AccessKey 只由服务端读取，不会写入数据库，也不会返回给浏览器。

## 启用方式

进入“系统设置 → 身份验证 → 基本身份验证”：

- 只开启“电子邮件验证”：新用户必须使用邮箱验证。
- 只开启“短信验证”：新用户必须使用中国大陆手机号验证。
- 两者同时开启：注册页显示邮箱和短信两个选项，用户任选其一。
- 两者都关闭：注册不要求验证码。

系统只有在五项阿里云环境变量齐全时才允许打开短信验证开关。

## 安全与频率限制

- 验证码为加密安全随机生成的 6 位数字，有效期 10 分钟。
- 启用 Redis 时，验证码以 HMAC 摘要存入 Redis；未启用 Redis 时退回当前进程内存。
- 同一手机号最多每分钟 1 条、每小时 5 条、每天 10 条；同一 IP 每分钟最多 10 次请求。
- 手机号以规范化后的中国大陆 11 位号码保存，并建立唯一索引。

## 排查

- 无法启用开关：检查五项环境变量是否齐全，并确认服务已经重新部署。
- 返回短信发送失败：在服务日志中查找阿里云返回的 `code`、`message` 和 `request_id`。
- 阿里云返回签名或模板错误：确认填写的是审核通过后的签名名称与模板 Code，且模板变量名为 `code`。
